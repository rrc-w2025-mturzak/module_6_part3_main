## About This Project

This repository contains my student portfolio website and the application components developed for the Module 6 DevOps assignment.

The purpose of this project is to demonstrate how software can be built, tested, containerized, deployed, and updated using modern DevOps tools and automation.

## Project Overview

Throughout this assignment, I will be working through the following tasks:

1. **Student Portfolio:** Customize the portfolio website with my own student information, profile image, and project details.
2. **Application Services:** Work with the backend, transactions, and syncer services that support the application.
3. **Docker:** Use Dockerfiles and containers to package the application services.
4. **Kubernetes:** Use Kubernetes deployment and service configuration files to run the application in a Minikube cluster.
5. **GitHub:** Store the project source code and deployment configuration in a GitHub repository.
6. **Continuous Integration (CI):** Configure GitHub Actions to build and publish updated Docker images when code is pushed.
7. **Continuous Delivery (CD):** Use Argo CD to monitor the GitHub repository and synchronize Kubernetes deployments automatically.
8. **GitOps:** Demonstrate automatic deployment updates, drift detection, and application rollback through Argo CD.

## Project Goal

The goal is to demonstrate an automated development and deployment workflow. Changes made to the application will be committed to GitHub, built into Docker images through GitHub Actions, and deployed to Kubernetes through Argo CD.

This project demonstrates how CI/CD and GitOps can make application deployment more consistent, repeatable, and efficient.
